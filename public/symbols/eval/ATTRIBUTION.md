# Eval Symbol Attribution

Symbols in this directory are sourced from two pools and used by the
new tiered eval flow (`eval-symbol` component).

## Mulberry Symbol Set

41 of the SVG files in this directory are taken unmodified from the
**Mulberry Symbol Set**:

- Source: <https://mulberrysymbols.org/>
- Repo: <https://github.com/mulberrysymbols/mulberry-symbols>
- License: Creative Commons Attribution-ShareAlike 4.0 International
  (CC BY-SA 4.0) — <https://creativecommons.org/licenses/by-sa/4.0/>
- Author: Garry Paxton (Straight-Street)

Modifications: none. Files are bundled verbatim from the `EN/`
directory of the source repo at master.

3. Share derivatives under the same CC BY-SA 4.0 terms.

## Custom inline SVGs

The remaining ~28 symbols rendered by the `eval-symbol` component
are hand-drawn inline SVGs defined in
`app/frontend/app/components/eval-symbol.js`. These are original
work, licensed under the same AGPLv3 terms as the rest of the
LingoLinq-AAC source.
