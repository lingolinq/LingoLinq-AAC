# One-way Notion "Compliance & Audit Posture" publish

Phase 4 "Cadence" deliverable (plan section 5.7, decision 5). After each `/audit-run`, the git
findings register stays the single source of truth and a **one-way** generated summary is pushed
to **one** read-only Notion page so non-devs (Dominic) and devs (Melissa/Traci/Omer) have a
shared place to see current posture - without a drift-prone bidirectional mirror.

## How to regenerate + publish (human-initiated)

1. After an `/audit-run` (register + citation-check green), regenerate the page body:
   ```
   ruby scripts/compliance-notion-publish.rb
   ruby scripts/compliance-notion-publish.rb --check   # must pass; CI runs this too
   ```
2. Preview the conversion without touching Notion:
   ```
   ruby scripts/compliance-notion-page-publish.rb --dry-run
   ```
   It prints the block count and table shapes (expect two tables, the 5-column headline and
   the 6-column findings table) and the title it will set.
3. Push, in place, to the recorded page:
   ```
   NOTION_TOKEN=$(op read 'op://LingoLinq Prod/NOTION_COMPLIANCE_API/credential') \
     ruby scripts/compliance-notion-page-publish.rb
   ```
   The publisher refuses a body that has drifted from the register, backs up the existing blocks
   to a JSON file (path printed; default the system temp dir), appends the new blocks, removes
   exactly the old ones, retitles the page with today's date and the audited SHA, and re-reads
   the page to verify the block count. If it aborts between append and delete, the page holds
   two copies; rerun and it converges.
4. Commit the regenerated `compliance-audit-page.md` with the register change it reflects.

## Hard rules (non-negotiable)

- **One-way only.** Git register -> Notion. Never read Notion back into the register; never treat
  the Notion page as a source of truth. It is stamped "GENERATED - DO NOT EDIT".
- **Human-initiated / human-gated.** No audit or compliance surface sends anything externally on
  its own. A person runs the push with the token in their environment; the generator never calls
  Notion, and no CI job or n8n workflow invokes the publisher.
- **Never auto-file, never delete.** The page stays under Compliance Home; the Notion Gardener
  does not move it and no one trashes it. It is regenerated in place and keeps its page id.
- **No student/patient data, ever.** The generator publishes headline counts + an open-findings
  table with file:line anchors only - no evidence snippets, no notes, no closed/superseded
  findings. The register itself carries code-only evidence.
- **The Compliance Posture Report stays DRAFT/unattested** until Scot signs. It is linked from the
  page, never embedded, and is not published externally until attested.
