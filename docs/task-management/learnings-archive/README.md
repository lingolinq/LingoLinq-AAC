# Learnings archive

- `LEARNINGS-2026-01_to_2026-09.md` is the original `LEARNINGS.md` monolith (683 entries,
  about 1.2 MB), moved here byte-for-byte on 2026-09-12 except for five entries prefixed
  `[SUPERSEDED ...]` because they describe the retired Render platform, Node 20, or an
  Ember 3.28 recipe. Grep it by surface keyword; do not read it linearly.
- `YYYY-MM.md` files are the append targets. When a task finishes, add its durable lesson
  to the current month's file (create it if missing) using the same shape as the curated
  file: a bold one-line title, two to seven lines, exactly one citation that resolves at
  HEAD, never a dated task-log filename.
- Promotion into `../LEARNINGS.md` (the curated, under-300-line file every agent reads) is
  a deliberate, reviewed edit that must satisfy the admission rule stated at the top of
  that file. Append here is cheap; promotion is curated.
