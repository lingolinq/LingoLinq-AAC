# Learnings archive — 2026-11

## 2026-11-02: unanchored report-name matches steal allowlisted prefixes

- **A substring match on `params['report']` that sits before a prefix branch will run for every
  allowlisted `status-` / `access-` / `device-` / `vocab-` / `grid-` name that contains that
  substring.** `match(/home_boards/)` ran the system-wide home-board census for
  `status-home_boards`. Exact equality keeps the prefix branch. A test that only asserts the leaked
  key is absent still passes if a single connection is dropped by `count <= 1`; seed two.
  Cite `admin_reports` in `app/controllers/api/organizations_controller.rb`.
