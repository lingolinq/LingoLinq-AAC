# 2026-10-12: "Try this Board" trial bar and "Use this board"

Branch: `traci/fix/scots-review-fixes`. Uncommitted at the time of writing.

## Asked
"Trying a board shows a trial bar, and 'Use this board' opens Speak Mode on it (whether in basic or modern
view) - basic should open speak mode in basic view, modern should open speak mode in modern view."

## Decisions (Traci, 2026-10-12)
- Try never changes the home board; "Use this board" makes it the home board, then opens Speak Mode.
- Basic: the trial browses the board (normal mode); Speak Mode starts on Use.
- Modern: its board page is always the speaking page (routes/user/board-detail.js: "Board-detail operates as
  speak mode"), so the trial is that page plus the bar; Use opens their own copy in Speak Mode.
- The bar: "Trying: <board name>", "Use this board", "Exit" (back to the picker). It replaces Modern's Back
  button and Basic's header "Set as Home Board" trial button.

## Before (verified live)
- Basic: Try -> Basic board page, normal mode, no bar. Modern: Try -> Modern board page in speak mode with a
  "Back to board picker" button. No "Use this board" anywhere.

## Changes
- `components/trial-bar.{js,hbs}` (new): shown for the tried board (Basic: its own marker, not in speak or
  edit mode; Modern: the board page's `try_origin_board`). Use = `copy_or_reuse_as_home` for the user the
  trial is for, preload + sync as the picker does, then: for yourself `app-state#home_in_speak_mode` with
  `force_board_state` = the new home board (it opens the right board page for the view); for a
  communicator an SLP tried it for, `after_pick_for_other` (as "Pick this Board"). Exit: Modern calls the
  page's existing `try_back_to_picker`; Basic clears its marker and returns to the picker.
- `board-preview-overlay.js#try_board`: the Modern marker also records who the trial is for.
- `templates/user/board-detail.hbs`: the bar above the sentence row; the Back button removed (line-neutral).
- `templates/board/index.hbs` (what the Basic board page renders): the bar at the top.
- `templates/application.hbs`: `<BasicTryHomeButton>` no longer rendered; the header "Set as Home" hides
  during any trial (line-neutral).
- `app.scss`: `.ll-trial-bar` styles; 44px buttons; Basic top margin measured against the header.
- `public/locales/en.json`: 4 new keys.
