# 2026-10-12: "Try this Board" trial bar and "Use this board"

Branch: `traci/fix/scots-review-fixes`. Uncommitted at the time of writing.

## Asked
"Trying a board shows a trial bar, and 'Use this board' opens Speak Mode on it (whether in basic or modern
view) - basic should open speak mode in basic view, modern should open speak mode in modern view."

## Decisions (Traci, 2026-10-12)
- Try never changes the home board; "Use this board" makes it the home board, then opens Speak Mode.
- Basic: the trial browses the board (normal mode); Speak Mode starts on Use.
- Modern: its board page is always the speaking page (routes/user/board-detail.js: "Board-detail operates as
  speak mode"), so the trial is that page plus the bar; Use opens their own copy in Speak Mode.
- The bar: "Trying: <board name>", "Use this board", "Exit" (back to the picker). It replaces Modern's Back
  button and Basic's header "Set as Home Board" trial button.

## Before (verified live)
- Basic: Try -> Basic board page, normal mode, no bar. Modern: Try -> Modern board page in speak mode with a
  "Back to board picker" button. No "Use this board" anywhere.

## Changes
- `components/trial-bar.{js,hbs}` (new): shown for the tried board (Basic: its own marker, not in speak or
  edit mode; Modern: the board page's `try_origin_board`). Use = `copy_or_reuse_as_home` for the user the
  trial is for, preload + sync as the picker does, then: for yourself `app-state#home_in_speak_mode` with
  `force_board_state` = the new home board (it opens the right board page for the view); for a
  communicator an SLP tried it for, `after_pick_for_other` (as "Pick this Board"). Exit: Modern calls the
  page's existing `try_back_to_picker`; Basic clears its marker and returns to the picker.
- `board-preview-overlay.js#try_board`: the Modern marker also records who the trial is for.
- `templates/user/board-detail.hbs`: the bar above the sentence row; the Back button removed (line-neutral).
- `templates/board/index.hbs` (what the Basic board page renders): the bar at the top.
- `templates/application.hbs`: `<BasicTryHomeButton>` no longer rendered; the header "Set as Home" hides
  during any trial (line-neutral).
- `app.scss`: `.ll-trial-bar` styles; 44px buttons; Basic top margin measured against the header.
- `public/locales/en.json`: 4 new keys.

## Tablet report fixes (2026-10-13, uncommitted at the time of writing)
Report (Modern, tablet): the trial's exit vanished in a folder; Home in a trial opened another board; Back lost
the picker's place. Then requested: "A trial bar on every page of a trial: Trying Vocal Flair 40 · Use this
board · Try another · Close"; "Home goes to the board being tried"; "Try another returns to the same spot in the
picker, with 'Recently tried' chips"; "Use this board opens Speak Mode right away with 'Vocal Flair 40 is now
your home board.' The copy finishes in the background."
- Bar on every page of the trial: `controllers/user/board-detail.js#try_origin_board` matches the tried board or
  any board whose trail (`board_detail_nav_history`) contains it; a new trial starts that trail empty
  (`board-preview-overlay.js#try_board`). Server `downstream_board_ids` was considered and rejected: it is only
  sent to someone who can delete the board (lib/json_api/board.rb). The bar names and adopts the TRIED board,
  not the folder on screen (`trial-bar.js`, marker carries `name`).
- Home during a trial (or while a chosen board is copying) goes to the tried board (`_trial_home`).
- Bar: "Trying <board>", "Use this board", "Try another" (was Exit), "Close" (new: ends the trial and goes home;
  Modern through the page's PIN-checked `exit_to_home`).
- Try another: the place is recorded when it happens (category in set_category, scroll and board on Try,
  `utils/board_picker_trials.js#remember_trial`), because the picker page rebuilds its picker during page
  changes (measured: a teardown save recorded a fresh picker's defaults). Restored by the page's own picker
  (`@searchAtTop`) for 5s after Try another. "Recently tried" chips (newest first, max 6) open the preview.
- Use this board, for yourself: Speak Mode opens at once on the tried board with the message; the copy runs in
  the background and becomes the home board; Home goes to the tried board meanwhile (`home_copy_pending`); a
  failed copy says the home board did not change. For a communicator: unchanged (copy, then return). Three
  existing trial-bar tests were rewritten for this request (the Use and failed-Use cases).
- Also: the Speak Mode tip names Modern's "Exit Boards: To Home Page" (Basic keeps "Exit Speak Mode"); the
  Speak button and the tip use the speaker icon, not a microphone.
- Live (emulated Galaxy Tab S4, Modern, aiden_parker): every step of the reported path, 0 page errors.
- Basic too: the trial covers the tried board's folders (`utils/board_picker_landing.js#basic_try_for` reads the
  browse trail, `get_history`; a new trial starts it empty), and the marker carries the board's name. Basic's
  header left button in a trial is "My Boards", not Home, so there is no Home to redirect there. Verified live
